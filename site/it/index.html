01

Installa l'integrazione della shell

ash funziona con bash, Fish e zsh. I comandi sconosciuti diventano prompt senza modificare le normali abitudini di comando. Posticipa quando hai bisogno di una pausa dall'elaborazione automatica dei prompt.

02

Aggiornamenti facili

ash update mantiene la tua installazione aggiornata con l'ultima versione. Il comando gestisce automaticamente i controlli della versione, i download e la verifica. Nessun aggiornamento di base o a sorpresa.

03

Mantieni il controllo

L'esecuzione dello strumento è vincolata da elenchi di autorizzazioni e negazioni esplicite e viene eseguito come utente. Sei tu a decidere cosa ash può toccare. Aggiungi i tuoi script Python a ~/.ash/tools o i plugin nativi a ~/.ash/plugins.

Inizia in piccolo

Dai al tuo guscio
un po' di compagnia.

Gli utenti Linux, macOS e FreeBSD possono installare l'ultima versione in un solo passaggio. Il programma di installazione verifica il download, installa su ~/.local/bin e configura l'integrazione Fish, zsh o bash rilevata, ricorrendo a bash.

ash install configura automaticamente il tuo provider AI: rileva una chiave API del provider cloud già impostata o un server di inferenza locale in esecuzione, altrimenti mostra un menu numerato per scegliere un provider e un modello. Oppure impostali tu stesso:

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'

Sono supportati Local, OpenAI, Anthropic, Google, Azure OpenAI, Mistral, Cohere, Groq, xAI, DeepSeek, Together AI, OpenRouter, HuggingFace, AWS Bedrock e qualsiasi altro provider con un'API compatibile con OpenAI.
