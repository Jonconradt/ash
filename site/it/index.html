01

Attiva l'integrazione della shell

ash funziona con bash, Fish e zsh. Il programma di installazione verificato chiede prima di aggiungere il proprio hook della shell gestita; i comandi sconosciuti diventano prompt una volta abilitati. Posticipa quando hai bisogno di una pausa dall'elaborazione automatica dei prompt.

02

Aggiornamenti facili

ash update mantiene la tua installazione aggiornata con l'ultima versione. Il comando gestisce automaticamente i controlli della versione, i download e la verifica. Nessun aggiornamento di base o a sorpresa.

03

Mantieni il controllo

L'esecuzione dello strumento è vincolata da elenchi di autorizzazioni e negazioni esplicite e viene eseguito come utente. Decidi tu cosaashè consentito toccare. Aggiungi i tuoi script Python a$XDG_DATA_HOME/ash/toolso plugin nativi a$XDG_DATA_HOME/ash/plugins.

Inizia in piccolo

Dai al tuo guscio
un po' di compagnia.

Gli utenti Linux, macOS e FreeBSD possono installare l'ultima versione in un solo passaggio. Installa Sigstorecosignprima in modo che l'installatore possa verificare il manifest del checksum firmato. Si installa su~/.local/bine chiede prima di aggiungere l'integrazione opt-in di Fish, zsh o bash shell.

Su macOS o Linux conBirra fatta in casa, installaashe i plug-in in bundle, quindi inizializza le risorse incorporate, le impostazioni del provider e l'integrazione della shell:

brew install Jonconradt/ash/ash
ash install --shell $SHELL --shell-integration

La formula viene aggiornata automaticamente per ogni versione stabile. Le disposizioni del comando di installazioneAshdelle risorse incorporate, configura l'integrazione della shell per la tua shell attuale e aiuta a configurare il tuo provider di intelligenza artificiale.

Su Debian o Ubuntu, installa e aggiornaashconAPP; sui sistemi compatibili con Fedora e RHEL, utilizzareDNF; Gli utenti di Arch Linux possono utilizzarePacman.

ash installconfigura automaticamente il tuo provider AI: rileva una chiave API del provider cloud già impostata o un server di inferenza locale in esecuzione, altrimenti mostra un menu numerato per scegliere un provider e un modello. Oppure impostali tu stesso:

export ASH_AI_AUTH_TOKEN='your-token'
export ASH_AI_ENDPOINT='https://ollama.com'
export ASH_AI_MODEL='gemma4:31b-cloud'

Sono supportati Local, OpenAI, Anthropic, Google, Azure OpenAI, Mistral, Cohere, Groq, xAI, DeepSeek, Together AI, OpenRouter, HuggingFace, AWS Bedrock e qualsiasi altro provider con un'API compatibile con OpenAI.
