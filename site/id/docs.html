Deskripsi

ash mengirimkan teks perintah ke titik akhir AI yang dikonfigurasi dan mencetak respons asisten. Jika tidak ada teks posisi yang disediakan, ash membaca teks perintah dari input standar non-interaktif.

Sub-perintah install menambahkan blok integrasi terkelola ke file startup shell. Bash menggunakan ~/.bashrc, dan zsh menggunakan ~/.zshrc.

Koneksi ke penyedia AI dibagikan melalui broker lokal. Kegagalan broker kembali ke HTTPS langsung.

AI dapat menggunakan systemd untuk menjadwalkan tugas di latar belakang. Ini bisa berupa pekerjaan yang berulang atau hanya sekali saja. Pekerjaan terjadwal menggunakan HTTPS langsung secara default.

ash mempertahankan ruang kerja awal dengan cakupan sesi di bawah ~/.ash/scratch/<session-id>/. Direktori awal yang basi dan tidak aktif akan dihapus secara otomatis setelah jendela retensi dikonfigurasi. Log riwayat disimpan di bawah ~/.ash/history/. File riwayat lama secara otomatis dibersihkan sesuai dengan kebijakan penyimpanan.

Alat, skrip, file, saluran, dan keluaran turunan adalah data yang tidak tepercaya dan tidak boleh mengesampingkan instruksi sistem atau pengguna. Fitur eksekusi alat bukan kotak pasir ketika eksekusi Python atau shell sewenang-wenang diaktifkan. Secara default Python diaktifkan, jadi berhati-hatilah.

Server MCP jarak jauh

Server MCP (Model Context Protocol) menyediakan alat yang dapat dipanggil oleh model AI. Ash mendukung server HTTP MCP Streamable jarak jauh dan menjaga sesi kliennya tetap di ash-broker di seluruh pemanggilan Ash di shell yang sama.

Daftarkan server dengan menambahkan URL-nya sendiri ke ~/.ash/.ash_allow, atau jalankan ash mcp add <url> dari server interaktif Ash cangkang. Perintah menghubungkan dan mendaftarkan server hanya setelah koneksi berhasil:

https://mcpplaygroundonline.com/mcp-complex-server

Otorisasi OAuth terbuka di browser desktop ketika GUI tersedia. Jika browser tidak dapat dibuka, Ash mencetak URL otorisasi yang dapat disalin dan menunggu di terminal. Gunakan ash mcp add <url> --no-browser untuk selalu menggunakan aliran terminal ini. Otorisasi URL manual masih memerlukan browser pada host yang sama; ini bukan alur OAuth tanpa browser.

Baris URL yang dimulai dengan http:// atau https:// adalah pendaftaran MCP, bukan perintah shell. Skema dikenali tanpa membedakan huruf besar dan kecil. Ash mendapatkan nama lokal server dari 8 karakter heksadesimal huruf kecil pertama SHA-256 di atas teks URL yang dipangkas. HTTPS diperlukan kecuali untuk pengembangan localhost; URL dengan kredensial, string kueri, atau fragmen yang disematkan akan ditolak. Untuk koneksi OAuth langsung, penemuan mengizinkan alamat IP non-publik hanya untuk otoritas MCP yang terdaftar; host OAuth lainnya tetap tunduk pada pemblokiran alamat non-publik. Proksi jalan keluar yang dikonfigurasi bertanggung jawab untuk memfilter alamat tujuannya. Perubahan dibaca pada permintaan Ash berikutnya.

Pendaftaran MCP tetap diaktifkan dengan ASH_STRICT=1. Hasil alat yang dikembalikan masih dianggap sebagai bukti yang tidak dapat dipercaya. Hanya daftarkan server yang Anda percayai: alat mereka dapat melakukan tindakan atas nama Anda. Untuk server yang dilindungi OAuth, Ash membuka browser ketika GUI tersedia sementara broker menangani panggilan balik dan token. Kredensial menggunakan manajer kredensial OS jika tersedia, atau file terenkripsi yang dilindungi oleh ASH_MCP_CREDENTIAL_KEY acak 32-byte yang disediakan pengguna. File ~/.ash/mcp.json yang ada tidak lagi dibaca; pindahkan URL server ke .ash_allow.

Jika inisialisasi MCP gagal, Ash melanjutkan permintaan tanpa alat MCP jarak jauh. Interaktif berjalan mencetak peringatan; proses non-interaktif gagal secara diam-diam. Pekerjaan terjadwal tidak memiliki broker shell per-interaktif dan oleh karena itu tidak dapat menggunakan alat MCP jarak jauh. Perintah terjadwal yang bergantung pada MCP mungkin masih berjalan namun dapat selesai tanpa tindakan atau data MCP yang diminta. Jangan jadwalkan perintah yang memerlukan MCP.

Lihat FAQ MCP untuk ikhtisar singkat dan catatan penyiapan.

Perintah

ash [--attach path]... [text ...]
Jalankan satu permintaan asisten. --attach melampirkan file (gambar atau dokumen) ke permintaan; dapat diulang. Ukuran dibatasi oleh ASH_ATTACHMENT_MAX_BYTES dan saat ini hanya dikirim melalui kabel ke penyedia yang kompatibel dengan OpenAI.
ash mcp add <url> [--no-browser]
Hubungkan dan daftarkan server MCP jarak jauh di .ash_allow yang efektif. Membuka otorisasi OAuth di browser desktop bila tersedia; kembali ke URL yang dapat disalin di terminal. --no-browser selalu menggunakan aliran terminal.
ash install [--shell bash|zsh] [--dry-run]
Instal atau perbarui integrasi shell. Ketika --shell dihilangkan, shell saat ini digunakan jika memungkinkan. --dry-run mempratinjau perubahan tanpa menulis. Saat interaktif, instal juga konfigurasi otomatis AI_ENDPOINT, AI_MODEL, dan AI_AUTH_TOKEN: ia lebih memilih kunci API penyedia cloud yang sudah ditetapkan (OpenAI, Anthropic, Google Gemini, Azure OpenAI, Mistral, Cohere, Groq, xAI, DeepSeek, Together AI, OpenRouter, atau HuggingFace), lalu server inferensi lokal yang berjalan (Ollama, LM Studio, llama.cpp/MLX/LocalAI, vLLM, text-generasi-webui, Jan, atau GPT4All), dan sebaliknya muncul dengan menu penyedia bernomor. Model dipilih dari daftar model titik akhir jika tersedia.
ash snooze [duration|off]
Jeda pemrosesan prompt shell otomatis. Standarnya adalah lima menit. Durasi menggunakan sintaksis Go seperti 30s, 5m, atau 1h. Gunakan off untuk segera melanjutkan.
ash update [--version vX.Y.Z] [--yes|--skip-customized]
Unduh dan instal rilis stabil macOS, Linux, atau FreeBSD terbaru untuk arsitektur saat ini ke ~/.local/bin/ash. Rilis memerlukan verifikasi Sigstore dan verifikasi SHA-256.

Lingkungan

AI_AUTH_TOKEN
Token pembawa opsional. Jika disetel, ini dikirim sebagai autentikasi pembawa dan diperlukan untuk titik akhir cloud. Alamat pribadi/LAN (RFC1918 IPv4, IPv6 ULA) dan nama host .local mDNS diperlakukan sebagai non-cloud (seperti localhost) kecuali ASH_STRICT=1 disetel.
AI_CACHE
Pengalih cache asli penyedia opsional. Diaktifkan secara default bila didukung; gunakan off atau false untuk menonaktifkan.
AI_ENDPOINT
URL dasar yang diperlukan untuk titik akhir API obrolan.
AI_MODEL
Nama model yang diperlukan dikirimkan ke titik akhir.
AI_PROVIDER
Penggantian penyedia opsional: anthropic, bedrock, cohere, gemini, google, ollama, atau openai. Jika tidak disetel, ash mendeteksi penyedia dari titik akhir.
AI_TIMEOUT
Batas waktu permintaan opsional. Bawaan: 3m.
ASH_ALWAYS_OPENAI_API
Tombol pengujian opsional. Jika benar, rutekan penyedia ollama melalui adaptor SDK yang kompatibel dengan OpenAI, bukan implementasi langsungnya. Default: aktif.
ASH_ATTACHMENT_MAX_BYTES
Ukuran maksimum opsional dalam byte untuk file yang diteruskan melalui --attach. Default: 10485760 (10 MiB).
ASH_HISTORY_MAX
Pesan riwayat maksimum opsional per kunci. Default: 40.
ASH_LOG_FILE
Jalur log debug opsional saat logging verbose diaktifkan.
ASH_LOG_MAX_BYTES
Ukuran log maksimum opsional sebelum rotasi. Default: 1048576.
ASH_MAX_AGENTS
Sub-agen maksimum opsional yang dihasilkan oleh satu proses induk. Default: 6.
ASH_MAX_TOOL_ITERS
Iterasi loop panggilan alat AI maksimum opsional. Default: 16.
ASH_RELEVANCE_WINDOW
Pengamatan alat terbaru opsional yang disertakan dalam status eksekusi. Default: 4.
ASH_RETRY_BASE_DELAY
Penundaan dasar backoff coba ulang opsional. Default: 250ms.
ASH_RETRY_MAX_ATTEMPTS
Upaya permintaan percobaan ulang opsional. Default: 3.
ASH_SCHEDULED_TASK
Tanda penjadwal internal yang digunakan oleh pemanggilan yang dikelola ash.
ASH_STREAM
Tombol opsional. Jika benar, mengalirkan respons dari penyedia yang adaptornya mendukungnya (saat ini hanya OpenAI). Default: aktif.
ASH_TASK_MAX
Batasan opsional pada tugas eksekusi yang berasal dari permintaan. Default: 6.
ASH_TASK_STALL_ROUNDS
Asisten opsional menghentikan putaran sebelum berhenti. Default: 2.
ASH_ALLOW
Daftar eksekusi opsional yang dipisahkan koma untuk run_unix_command. Jika tidak, ~/.ash/.ash_allow digunakan saat ada; penggantian ini tidak memperluas token Ash internal.
ASH_DENY
Daftar penolakan opsional yang dipisahkan koma untuk memblokir perintah, alat, dan plugin secara eksplisit. Jika tidak, ~/.ash/.ash_deny akan digunakan jika ada.
ASH_TOOL_OUTPUT_MAX
Output alat pengambilan maksimum opsional dalam byte. Default: 8192.
ASH_TOOL_TIMEOUT
Batas waktu perintah alat lokal opsional. Default: 15s.
ASH_VERBOSE
Dasbor eksekusi dan logging debug opsional. Nilai seperti 1, true, on, dan debug mengaktifkannya.
SESSION_ID
Pengidentifikasi sesi untuk riwayat persisten dan penamaan log. Dihasilkan secara otomatis untuk proses interaktif ketika tidak ada.

File

  • ~/.ash/.ash_system — perintah sistem kanonik. $TOOLS_DIR_LIST, $PLUGINS_DIR_LIST, dan $IF_PYTHON_AVAILABLE merupakan pengganti Ash internal, bukan variabel lingkungan.
  • ~/.ash/.ash_allow — perintah kanonik, alat, dan daftar plugin yang diizinkan. Izin arahan $TOOLS_DIR_LIST dan $PLUGINS_DIR_LIST yang berdiri sendiri mengizinkan skrip terkelola reguler dan plugin asli; ganti dengan nama literal untuk kebijakan yang membatasi.
  • ~/.ash/.ash_deny — file daftar penolakan kanonik untuk memblokir perintah, alat, atau plugin tertentu.
  • ~/.ash/plugins/ — direktori plugin biner asli.
  • ~/.ash/history/ — file riwayat percakapan.
  • ~/.ash/scratch/ — coretan dalam cakupan sesi files.
  • ~/.ash/.ash_snooze_until — berakhirnya penundaan otomatis secara cepat.

Status keluar

ash menghasilkan 0 jika berhasil. Ia mengembalikan bukan nol ketika konfigurasi, permintaan jaringan, atau eksekusi alat gagal.

Contoh

echo "summarize this directory" | ash
ash install --shell bash
ash install --shell zsh --dry-run
