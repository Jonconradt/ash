01

Instal integrasi shell

ash berfungsi dengan bash, Fish, dan zsh. Perintah yang tidak diketahui menjadi petunjuk tanpa mengubah kebiasaan perintah normal Anda. Tunda saat Anda perlu istirahat dari pemrosesan perintah otomatis.

02

Pembaruan mudah

ash update terus memperbarui instalasi Anda dengan rilis terbaru. Perintah ini menangani pemeriksaan versi, pengunduhan, dan verifikasi secara otomatis. Tidak ada pembaruan latar belakang atau kejutan.

03

Tetap memegang kendali

Eksekusi alat dibatasi oleh daftar izin dan tolak yang eksplisit dan dijalankan sebagai pengguna Anda. Anda memutuskan apa yang ash boleh disentuh. Tambahkan skrip Python Anda sendiri ke ~/.ash/tools atau plugin asli ke ~/.ash/plugins.

Pengguna Linux, macOS, dan FreeBSD dapat menginstal rilis terbaru dalam satu langkah. Pemasang memverifikasi unduhan, memasang ke ~/.local/bin, dan mengonfigurasi integrasi Fish, zsh, atau bash yang terdeteksi, lalu kembali ke bash.

ash install mengonfigurasi otomatis penyedia AI Anda: ia mendeteksi kunci API penyedia cloud yang sudah disetel atau server inferensi lokal yang sedang berjalan, jika tidak, ia akan menampilkan menu bernomor untuk memilih penyedia dan model. Atau atur sendiri:

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'
