01

安装 shell 集成

ash 适用于 bash、Fish 和 zsh。未知命令变成提示，不改变你正常的命令习惯。当您需要从自动提示处理中休息一下时，请小睡一下。

02

轻松更新

ash update 让您的安装保持最新版本。该命令自动处理版本检查、下载和验证。没有背景或意外更新。

03

保持控制

工具执行受到显式允许和拒绝列表的限制，并以您的用户身份运行。您决定允许触摸什么ash。将您自己的 Python 脚本添加到 ~/.ash/tools 或将本机插件添加到 ~/.ash/plugins。

从小事做起

给你的外壳
一些陪伴。

Linux、macOS 和 FreeBSD 用户可以一步安装最新版本。安装程序会验证下载，安装到 ~/.local/bin，并配置检测到的 Fish、zsh 或 bash 集成，然后回退到 bash。

ash install 自动配置您的 AI 提供商：它会检测已设置的云提供商 API 密钥或正在运行的本地推理服务器，否则会显示一个编号菜单以选择提供商和模型。或者自己设置：

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'

支持 Local、OpenAI、Anthropic、Google、Azure OpenAI、Mistral、Cohere、Groq、xAI、DeepSeek、Together AI、OpenRouter、HuggingFace、AWS Bedrock 以及具有 OpenAI 兼容 API 的任何其他提供商。
