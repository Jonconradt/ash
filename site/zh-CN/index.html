01

选择加入 shell 集成

ash 适用于 bash、Fish 和 zsh。经过验证的安装程序在添加其托管 shell 挂钩之前会进行询问；一旦启用，未知命令就会变成提示。当您需要从自动提示处理中休息一下时，请小睡一下。

02

轻松更新

ash update 让您的安装保持最新版本。该命令自动处理版本检查、下载和验证。没有背景或意外更新。

03

保持控制

工具执行受到显式允许和拒绝列表的限制，并以您的用户身份运行。你决定什么ash被允许触摸。添加您自己的 Python 脚本$XDG_DATA_HOME/ash/tools或本机插件$XDG_DATA_HOME/ash/plugins。

一些陪伴。

Linux、macOS 和 FreeBSD 用户可以一步安装最新版本。安装 Sigstorecosign首先，安装程序可以验证签名的校验和清单。它安装到~/.local/bin并在添加选择加入 Fish、zsh 或 bash shell 集成之前进行询问。

在 macOS 或 Linux 上自制， 安装ash及其捆绑的插件，然后初始化其嵌入式资产、提供程序设置和 shell 集成：

brew install Jonconradt/ash/ash
ash install --shell $SHELL --shell-integration

该公式会针对每个稳定版本自动更新。安装命令规定Ash的嵌入式资产，为您当前的 shell 设置 shell 集成，并帮助配置您的 AI 提供程序。

在 Debian 或 Ubuntu 上，安装并更新ash和易于;在 Fedora 和 RHEL 兼容系统上，使用地下城与勇士; Arch Linux 用户可以使用吃豆人。

ash install自动配置您的 AI 提供商：它会检测已设置的云提供商 API 密钥或正在运行的本地推理服务器，否则它会显示一个编号菜单来选择提供商和模型。或者自己设置这些：

export ASH_AI_AUTH_TOKEN='your-token'
export ASH_AI_ENDPOINT='https://ollama.com'
export ASH_AI_MODEL='gemma4:31b-cloud'

支持 Local、OpenAI、Anthropic、Google、Azure OpenAI、Mistral、Cohere、Groq、xAI、DeepSeek、Together AI、OpenRouter、HuggingFace、AWS Bedrock 以及具有 OpenAI 兼容 API 的任何其他提供商。
