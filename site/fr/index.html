01

Activer l'intégration du shell

ash fonctionne avec bash, Fish et zsh. Le programme d'installation vérifié demande avant d'ajouter son hook shell géré ; les commandes inconnues deviennent des invites une fois que vous l'activez. Répétez lorsque vous avez besoin d'une pause dans le traitement automatique des invites.

02

Mises à jour faciles

Actualisez via le gestionnaire, ou ash update pour Release installé dans ~/.local/bin. Choisissez Release, Beta ou Nightly via les dépôts compatibles. Aucune mise à jour surprise en arrière-plan.

03

Gardez le contrôle

L'exécution de l'outil est limitée par des listes d'autorisation et de refus explicites et s'exécute en tant qu'utilisateur. Vous décidez quoiashest autorisé à toucher. Ajoutez vos propres scripts Python à$XDG_DATA_HOME/ash/toolsou des plugins natifs pour$XDG_DATA_HOME/ash/plugins.
