01

Installer l'intégration du shell

ash fonctionne avec bash, Fish et zsh. Les commandes inconnues deviennent des invites sans modifier vos habitudes de commande normales. Répétez lorsque vous avez besoin d'une pause dans le traitement automatique des invites.

02

Mises à jour faciles

ash update maintient votre installation à jour avec la dernière version. La commande gère automatiquement les vérifications de version, les téléchargements et la vérification. Aucune mise à jour en arrière-plan ou surprise.

03

Gardez le contrôle

L'exécution de l'outil est limitée par des listes d'autorisation et de refus explicites et s'exécute en tant qu'utilisateur. Vous décidez ce que ash est autorisé à toucher. Ajoutez vos propres scripts Python à ~/.ash/tools ou des plugins natifs à ~/.ash/plugins.

Commencez petit

Donnez à votre coquille
un peu de compagnie.

Les utilisateurs de Linux, macOS et FreeBSD peuvent installer la dernière version en une seule étape. Le programme d'installation vérifie le téléchargement, installe sur ~/.local/bin et configure l'intégration Fish, zsh ou bash détectée, en revenant à bash.

ash install configure automatiquement votre fournisseur d'IA : il détecte une clé API de fournisseur de cloud déjà définie ou un serveur d'inférence local en cours d'exécution, sinon il affiche un menu numéroté pour choisir un fournisseur et un modèle. Ou définissez-les vous-même :

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'

Local, OpenAI, Anthropic, Google, Azure OpenAI, Mistral, Cohere, Groq, xAI, DeepSeek, Together AI, OpenRouter, HuggingFace, AWS Bedrock et tout autre fournisseur doté d'une API compatible OpenAI sont pris en charge.
