01

الاشتراك في تكامل الصدفة

يعمل ash مع bash وFish وzsh. يسأل المثبت الذي تم التحقق منه قبل إضافة ربط الصدفة المُدار الخاص به؛ تصبح الأوامر غير المعروفة مطالبات بمجرد تمكينها. غفوة عندما تحتاج إلى استراحة من المعالجة السريعة التلقائية.

02

تحديثات سهلة

ash update تحافظ على تحديث التثبيت بأحدث إصدار. يتعامل الأمر مع عمليات التحقق من الإصدار والتنزيلات والتحقق تلقائيًا. لا توجد خلفية أو تحديثات مفاجئة.

03

البقاء في السيطرة

يتم تقييد تنفيذ الأداة من خلال قوائم السماح والرفض الصريحة ويتم تشغيلها كمستخدم لديك. عليك أن تقرر ماashيسمح للمس. أضف نصوص بايثون الخاصة بك إلى$XDG_DATA_HOME/ash/toolsأو المكونات الإضافية الأصلية ل$XDG_DATA_HOME/ash/plugins.

ابدأ صغيرًا

امنح صدفتك
بعض الرفقة.

يمكن لمستخدمي Linux وmacOS وFreeBSD تثبيت الإصدار الأحدث في خطوة واحدة. قم بتثبيت سيجستورcosignأولاً حتى يتمكن المثبت من التحقق من بيان المجموع الاختباري الموقع. يتم تثبيته ل~/.local/binويسأل قبل إضافة تكامل Fish أو zsh أو bash Shell.

على نظام التشغيل MacOS أو Linux معالبيرة المنزلية، ثَبَّتَashوالمكونات الإضافية المجمعة، ثم قم بتهيئة أصولها المضمنة وإعدادات الموفر وتكامل الصدفة:

brew install Jonconradt/ash/ash
ash install --shell $SHELL --shell-integration

يتم تحديث الصيغة تلقائيًا لكل إصدار ثابت. أحكام أمر التثبيتAshالأصول المضمنة، ويقوم بإعداد تكامل Shell لـ Shell الحالي الخاص بك، ويساعد في تكوين موفر الذكاء الاصطناعي الخاص بك.

على Debian أو Ubuntu، قم بالتثبيت والتحديثashمعايه بي تي; على الأنظمة المتوافقة مع Fedora وRHEL، استخدمDNF; يمكن لمستخدمي Arch Linux استخدامهبكمن.

ash installيقوم تلقائيًا بتكوين موفر الذكاء الاصطناعي الخاص بك: فهو يكتشف مفتاح API لموفر السحابة الذي تم تعيينه بالفعل أو خادم استدلال محلي قيد التشغيل، وإلا فإنه يعرض قائمة مرقمة لاختيار موفر ونموذج. أو قم بتعيينها بنفسك:

export ASH_AI_AUTH_TOKEN='your-token'
export ASH_AI_ENDPOINT='https://ollama.com'
export ASH_AI_MODEL='gemma4:31b-cloud'

يتم دعم Local وOpenAI وAnthropic وGoogle وAzure OpenAI وMistral وCohere وGroq وxAI وDeepSeek وTogether AI وOpenRouter وHuggingFace وAWS Bedrock وأي موفر آخر لديه واجهة برمجة تطبيقات متوافقة مع OpenAI.
