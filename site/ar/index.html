01

تثبيت تكامل الصدفة

ash يعمل مع bash وFish وzsh. تصبح الأوامر غير المعروفة مطالبات دون تغيير عادات الأوامر العادية. غفوة عندما تحتاج إلى استراحة من المعالجة السريعة التلقائية.

02

تحديثات سهلة

ash update تحافظ على تحديث التثبيت بأحدث إصدار. يتعامل الأمر مع عمليات التحقق من الإصدار والتنزيلات والتحقق تلقائيًا. لا توجد خلفية أو تحديثات مفاجئة.

03

البقاء متحكمًا

يكون تنفيذ الأداة مقيدًا بقوائم السماح والرفض الصريحة ويتم تشغيلها كمستخدم لديك. عليك أن تقرر ما هو ash المسموح بلمسه. أضف نصوص Python الخاصة بك إلى ~/.ash/tools أو المكونات الإضافية الأصلية إلى ~/.ash/plugins.

يمكن لمستخدمي Linux وmacOS وFreeBSD تثبيت أحدث إصدار في خطوة واحدة. يتحقق المثبت من التنزيل، ويتم التثبيت على ~/.local/bin، ويقوم بتكوين تكامل Fish أو zsh أو bash، والعودة إلى bash.

ash install يقوم بتهيئة موفر الذكاء الاصطناعي تلقائيًا: فهو يكتشف مفتاح API لموفر السحابة الذي تم تعيينه بالفعل أو خادم استدلال محلي قيد التشغيل، وإلا فإنه يعرض قائمة مرقمة لاختيار الموفر والنموذج. أو قم بتعيينها بنفسك:

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'

يتم دعم Local وOpenAI وAnthropic وGoogle وAzure OpenAI وMistral وCohere وGroq وxAI وDeepSeek وTogether AI وOpenRouter وHuggingFace وAWS Bedrock وأي موفر آخر لديه واجهة برمجة تطبيقات متوافقة مع OpenAI.
