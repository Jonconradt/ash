أوامر المستخدم · ash(1)

ash الوثائق

مساعد الصدفة العملي لسير عمل الأوامر التي لم يتم العثور عليها. هذه الصفحة هي إصدار الويب من ash(1) صفحة الدليل.

المحتويات الملخص الوصف خوادم MCP الأوامر البيئة الملفات خروج الحالة أمثلة

الملخص

ash [text ...]
ash install [--shell bash|zsh] [--dry-run] [--overwrite]
ash mcp add <url> [--no-browser]
ash snooze [duration|off]
ash update [--version vX.Y.Z] [--yes|--skip-customized]

الوصف

ash يرسل نصًا سريعًا إلى نقطة نهاية الذكاء الاصطناعي التي تم تكوينها ويطبع استجابة المساعد. عندما لا يتم توفير نص موضعي، يقرأ ash النص الموجه من الإدخال القياسي غير التفاعلي.

يضيف الأمر الفرعي install كتلة تكامل مُدارة إلى ملفات بدء التشغيل Shell. يستخدم Bash ~/.bashrc، ويستخدم zsh ~/.zshrc.

تتم مشاركة الاتصالات بموفر الذكاء الاصطناعي من خلال وسيط محلي. يعود فشل الوسيط إلى HTTPS المباشر.

يمكن للذكاء الاصطناعي استخدام systemd لجدولة مهام الخلفية. يمكن أن تكون هذه وظائف متكررة أو لمرة واحدة. تستخدم المهام المجدولة HTTPS المباشر بشكل افتراضي.

ash يحتفظ بمساحة عمل مؤقتة على مستوى الجلسة ضمن ~/.ash/scratch/<session-id>/. تتم إزالة الدلائل القديمة والخمول تلقائيًا بعد نافذة الاستبقاء التي تم تكوينها. يتم تخزين سجلات التاريخ تحت ~/.ash/history/. يتم تنظيف ملفات السجل القديم تلقائيًا وفقًا لسياسة الاستبقاء.

تعد الأداة والبرنامج النصي والملف والمرسل والمخرجات التابعة بيانات غير موثوق بها ويجب ألا تتجاوز تعليمات النظام أو المستخدم. لا تكون ميزة تنفيذ الأداة بمثابة وضع الحماية عند تمكين التنفيذ التعسفي لـ Python أو Shell. افتراضيًا، يتم تمكين لغة Python، لذا احذر.

خوادم MCP البعيدة

توفر خوادم MCP (بروتوكول سياق النموذج) أدوات يمكن لنموذج الذكاء الاصطناعي الاتصال بها. Ash يدعم خوادم HTTP MCP القابلة للتدفق عن بُعد ويحافظ على جلسات عمل العملاء في ash-broker عبر استدعاءات Ash في نفس الصدفة.

قم بتسجيل الخادم عن طريق إضافة عنوان URL الخاص به بنفسه إلى ~/.ash/.ash_allow، أو تشغيل ash mcp add <url> من موقع تفاعلي. Ash قذيفة. يقوم الأمر بالاتصال بالخادم وتسجيله فقط بعد الاتصال الناجح:

https://mcpplaygroundonline.com/mcp-complex-server

يتم فتح ترخيص OAuth في متصفح سطح المكتب عند توفر واجهة المستخدم الرسومية. إذا تعذر فتح المتصفح، فسيقوم Ash بطباعة عنوان URL للتفويض القابل للنسخ وينتظر في الجهاز. استخدم ash mcp add <url> --no-browser لاستخدام هذا التدفق الطرفي دائمًا. لا يزال ترخيص URL اليدوي يتطلب متصفحًا على نفس المضيف؛ فهو ليس تدفق OAuth بدون متصفح.

أسطر URL التي تبدأ بـ http:// أو https:// هي تسجيلات MCP، وليست أوامر Shell. يتم التعرف على المخططات بشكل غير حساس لحالة الأحرف. Ash يستمد الاسم المحلي للخادم من أول 8 أحرف ست عشرية صغيرة من SHA-256 فوق نص عنوان URL المشذب. HTTPS مطلوب باستثناء تطوير المضيف المحلي؛ يتم رفض عناوين URL التي تحتوي على بيانات اعتماد أو سلاسل استعلام أو أجزاء مضمنة. بالنسبة لاتصالات OAuth المباشرة، يسمح الاكتشاف بعناوين IP غير العامة فقط لسلطة MCP المسجلة بالضبط؛ يظل مضيفو OAuth الآخرون خاضعين لحظر العناوين غير العامة. وكيل الخروج الذي تم تكوينه مسؤول عن تصفية عناوين الوجهة الخاصة به. تتم قراءة التغييرات عند طلب Ash التالي.

تظل تسجيلات MCP ممكنة مع ASH_STRICT=1. لا يزال يتم التعامل مع مخرجات الأداة المرتجعة كدليل غير موثوق به. قم بتسجيل الخوادم التي تثق بها فقط: قد تؤدي أدواتها إجراءات نيابة عنك. بالنسبة للخوادم المحمية بـ OAuth، يفتح Ash المتصفح عندما تكون واجهة المستخدم الرسومية متاحة بينما يتعامل الوسيط مع رد الاتصال والرموز المميزة. تستخدم بيانات الاعتماد مدير بيانات اعتماد نظام التشغيل عندما يكون ذلك متاحًا، أو ملفًا مشفرًا محميًا بملف عشوائي 32 بايت يقدمه المستخدم ASH_MCP_CREDENTIAL_KEY. لم تعد ملفات ~/.ash/mcp.json الموجودة قابلة للقراءة؛ انقل عناوين URL للخادم إلى .ash_allow.

إذا فشلت تهيئة MCP، فسيواصل Ash الطلب بدون أدوات MCP عن بعد. عمليات التشغيل التفاعلية تطبع تحذيرًا؛ عمليات التشغيل غير التفاعلية تفشل بهدوء. لا تحتوي المهام المجدولة على وسيط لكل واجهة تفاعلية، وبالتالي لا يمكنها استخدام أدوات MCP عن بعد. قد يستمر تشغيل الموجه المجدول الذي يعتمد على MCP ولكن يمكن أن ينتهي بدون إجراء MCP أو البيانات المطلوبة. لا تقم بجدولة المطالبات التي تتطلب MCP.

راجع الأسئلة الشائعة لـ MCP للحصول على نظرة عامة سريعة وملاحظات الإعداد.

الأوامر

ash [--attach path]... [text ...]
تشغيل طلب مساعد واحد. --attach إرفاق ملف (صورة أو مستند) بالطلب؛ قابل للتكرار. الحجم محدود بـ ASH_ATTACHMENT_MAX_BYTES ويتم إرساله حاليًا عبر السلك فقط إلى مقدمي الخدمة المتوافقين مع OpenAI.
ash mcp add <url> [--no-browser]
قم بالاتصال وتسجيل خادم MCP عن بعد في .ash_allow الفعال. يفتح ترخيص OAuth في متصفح سطح المكتب عندما يكون متاحًا؛ يعود إلى عنوان URL القابل للنسخ في الجهاز. --no-browser يستخدم دائمًا التدفق الطرفي.
ash install [--shell bash|zsh] [--dry-run]
تثبيت أو تحديث تكامل Shell. عند حذف --shell، يتم استخدام الغلاف الحالي عندما يكون ذلك ممكنًا. --dry-run يقوم بمعاينة التغييرات بدون كتابة. عندما يكون التثبيت تفاعليًا، يقوم التثبيت أيضًا بالتكوين التلقائي AI_ENDPOINT وAI_MODEL وAI_AUTH_TOKEN: فهو يفضل مفتاح API لموفر السحابة الذي تم تعيينه بالفعل (OpenAI أو Anthropic أو Google Gemini أو Azure OpenAI أو Mistral أو Cohere أو Groq أو xAI أو DeepSeek أو Together AI أو OpenRouter أو HuggingFace)، ثم خادم استدلال محلي قيد التشغيل (Ollama أو LM Studio أو llama.cpp/MLX/LocalAI أو vLLM أو text-generation-webui أو Jan أو GPT4All)، وبخلاف ذلك، يتم المطالبة بقائمة موفر مرقمة. يتم اختيار النموذج من قائمة نماذج نقطة النهاية عندما يكون متاحًا.
ash snooze [duration|off]
إيقاف مؤقت للمعالجة التلقائية لمطالبات Shell. الافتراضي هو خمس دقائق. تستخدم الفترات بناء جملة Go مثل 30s أو 5m أو 1h. استخدم off للاستئناف على الفور.
ash update [--version vX.Y.Z] [--yes|--skip-customized]
قم بتنزيل وتثبيت أحدث إصدار ثابت من macOS أو Linux أو FreeBSD للبنية الحالية في ~/.local/bin/ash. تتطلب الإصدارات التحقق من Sigstore والتحقق من SHA-256.

البيئة

AI_AUTH_TOKEN
رمز حامل اختياري. عند التعيين، يتم إرساله كمصادقة للحامل ويكون مطلوبًا لنقاط النهاية السحابية. يتم التعامل مع عناوين الشبكة المحلية/الخاصة (RFC1918 IPv4 وIPv6 ULA) وأسماء مضيفات .local mDNS على أنها غير سحابية (مثل localhost) ما لم يتم تعيين ASH_STRICT=1.
AI_CACHE
تبديل اختياري لذاكرة التخزين المؤقت الأصلية للموفر. يتم تمكينه افتراضيًا عند دعمه؛ استخدم off أو false للتعطيل.
AI_ENDPOINT
عنوان URL الأساسي المطلوب لنقطة نهاية واجهة برمجة تطبيقات الدردشة.
AI_MODEL
تم إرسال اسم النموذج المطلوب إلى نقطة النهاية.
AI_PROVIDER
تجاوز الموفر الاختياري: anthropic، bedrock، cohere، gemini، google، ollama، أو openai. عند عدم الضبط، يكتشف ash الموفر من نقطة النهاية.
AI_TIMEOUT
مهلة الطلب الاختيارية. الافتراضي: 3m.
ASH_ALWAYS_OPENAI_API
تبديل الاختبار الاختياري. عندما يكون الأمر حقيقيًا، يقوم بتوجيه موفر ollama من خلال محول SDK المتوافق مع OpenAI بدلاً من التنفيذ المدلفن يدويًا. الافتراضي: تشغيل.
ASH_ATTACHMENT_MAX_BYTES
الحجم الأقصى الاختياري بالبايت للملف الذي تم تمريره عبر --attach. الافتراضي: 10485760 (10 MiB).
ASH_HISTORY_MAX
الحد الأقصى الاختياري لرسائل السجل لكل مفتاح. الافتراضي: 40.
ASH_LOG_FILE
مسار سجل تصحيح اختياري عند تمكين التسجيل المطول.
ASH_LOG_MAX_BYTES
الحد الأقصى الاختياري لحجم السجل قبل التدوير. الافتراضي: 1048576.
ASH_MAX_AGENTS
الحد الأقصى الاختياري للوكلاء الفرعيين الذي تم إنشاؤه بواسطة عملية رئيسية واحدة. الافتراضي: 6.
ASH_MAX_TOOL_ITERS
الحد الأقصى الاختياري لتكرارات حلقة استدعاء أداة الذكاء الاصطناعي. الافتراضي: 16.
ASH_RELEVANCE_WINDOW
ملاحظات الأداة الحديثة الاختيارية المضمنة في حالة التنفيذ. الافتراضي: 4.
ASH_RETRY_BASE_DELAY
تأخير قاعدة إعادة محاولة التراجع الاختيارية. الافتراضي: 250ms.
ASH_RETRY_MAX_ATTEMPTS
محاولات طلب اختيارية قابلة لإعادة المحاولة. الافتراضي: 3.
ASH_SCHEDULED_TASK
علامة الجدولة الداخلية المستخدمة بواسطة الدعوات المُدارة ash.
ASH_STREAM
تبديل اختياري. عندما يكون الأمر حقيقيًا، يتم بث الاستجابة من الموفرين الذين يدعمها المحول الخاص بهم (حاليًا OpenAI فقط). الافتراضي: تشغيل.
ASH_TASK_MAX
حد أقصى اختياري لمهام التنفيذ المستمدة من الطلب. الافتراضي: 6.
ASH_TASK_STALL_ROUNDS
جولات المماطلة المساعدة الاختيارية قبل التوقف. الافتراضي: 2.
ASH_ALLOW
القائمة المسموح بها القابلة للتنفيذ الاختيارية مفصولة بفواصل لـ run_unix_command. بخلاف ذلك يتم استخدام ~/.ash/.ash_allow عند وجوده؛ لا يؤدي هذا التجاوز إلى توسيع رموز Ash الداخلية.
ASH_DENY
قائمة رفض اختيارية مفصولة بفواصل لحظر الأوامر والأدوات والمكونات الإضافية بشكل صريح. بخلاف ذلك، يتم استخدام ~/.ash/.ash_deny عند وجوده.
ASH_TOOL_OUTPUT_MAX
الحد الأقصى الاختياري لإخراج الأداة الملتقطة بالبايت. الافتراضي: 8192.
ASH_TOOL_TIMEOUT
مهلة أمر الأداة المحلية الاختيارية. الافتراضي: 15s.
ASH_VERBOSE
تسجيل تصحيح الأخطاء ولوحة معلومات التنفيذ الاختيارية. تعمل القيم مثل 1 وtrue وon وdebug على تمكينها.
SESSION_ID
معرف الجلسة للسجل المستمر وتسمية السجل. يتم إنشاؤه تلقائيًا لعمليات التشغيل التفاعلية عند فقدانه.

الملفات

  • ~/.ash/.ash_system — موجه النظام الأساسي. $TOOLS_DIR_LIST و$PLUGINS_DIR_LIST و$IF_PYTHON_AVAILABLE هي بدائل Ash داخلية، وليست متغيرات بيئة أبدًا.
  • ~/.ash/.ash_allow — القائمة المسموح بها للأوامر والأدوات والمكونات الإضافية الأساسية. تسمح التوجيهات المستقلة $TOOLS_DIR_LIST و$PLUGINS_DIR_LIST بالبرامج النصية المُدارة العادية والمكونات الإضافية الأصلية؛ استبدلها بأسماء حرفية للسياسة المقيدة.
  • ~/.ash/.ash_deny - ملف قائمة الحظر الأساسي لحظر أوامر أو أدوات أو مكونات إضافية محددة.
  • ~/.ash/plugins/ - دليل المكونات الإضافية الثنائية الأصلية.
  • ~/.ash/history/ - ملفات محفوظات المحادثة.
  • ~/.ash/scratch/ - خدش على نطاق الجلسة. الملفات.
  • ~/.ash/.ash_snooze_until — انتهاء صلاحية التأجيل التلقائي.

حالة الخروج

ash تُرجع 0 عند النجاح. يُرجع قيمة غير صفرية عند فشل التكوين أو طلبات الشبكة أو تنفيذ الأداة.

أمثلة

echo "summarize this directory" | ash
ash install --shell bash
ash install --shell zsh --dry-run
