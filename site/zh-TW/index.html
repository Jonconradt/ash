01

安裝 shell 整合

ash 適用於 bash、Fish 和 zsh。未知指令變成提示，不改變你正常的指令習慣。當您需要從自動提示處理中休息一下時，請小睡一下。

02

輕鬆更新

ash update 讓您的安裝保持最新版本。此指令會自動處理版本檢查、下載和驗證。沒有背景或意外更新。

03

保持控制

工具執行受到明確允許和拒絕清單的限制，並以您的使用者身分運作。您決定允許觸摸什麼ash。將您自己的 Python 腳本新增至 ~/.ash/tools 或將本機外掛程式新增至 ~/.ash/plugins。

從小事做起

給你的外殼
一些陪伴。

Linux、macOS 和 FreeBSD 使用者可以一步安裝最新版本。安裝程式會驗證下載，安裝到 ~/.local/bin，並配置偵測到的 Fish、zsh 或 bash 集成，然後回退到 bash。

ash install 自動設定您的 AI 提供者：它會偵測已設定的雲端提供者 API 金鑰或正在執行的本機推理伺服器，否則會顯示編號選單以選擇提供者和模型。或自行設定：

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'

支援 Local、OpenAI、Anthropic、Google、Azure OpenAI、Mistral、Cohere、Groq、xAI、DeepSeek、Together AI、OpenRouter、HuggingFace、AWS Bedrock 以及具有 OpenAI 相容 API 的任何其他提供者。
