ash 文檔

用於命令未找到工作流程的實用 shell 助理。此頁面是可安裝的網路版本ash(1)手冊頁。

內容 概要 描述 MCP伺服器 命令 環境 文件 退出狀態 範例

概要

ash [text ...]
ash install [--shell bash|zsh] [--dry-run] [--overwrite]
ash mcp add <url> [--no-browser]
ash snooze [duration|off]
ash update [--version vX.Y.Z] [--yes|--skip-customized]

描述

ash向配置的 AI 端點發送提示文字並列印助理回應。當沒有提供位置文字時，ash從非互動式標準輸入讀取提示文字。

這install子命令將託管整合塊新增至 shell 啟動檔案。 bash 使用~/.bashrc和 zsh 使用~/.zshrc。

與人工智慧提供者的連接透過​​本地代理共享。代理故障會退回到直接 HTTPS。

AI可以使用systemd來安排後台任務。這些工作可以是重複性工作，也可以是一次性工作。預設情況下，排程作業使用直接 HTTPS。

ash 在下維護一個會話範圍的臨時工作空間~/.ash/scratch/<session-id>/。在配置的保留視窗之後，陳舊和空閒的暫存目錄將自動刪除。歷史日誌儲存在~/.ash/history/。舊的歷史文件會根據保留策略自動清理。

工具、腳本、檔案、管道和子輸出是不受信任的數據，不得覆蓋系統或使用者指令。啟用任意 Python 或 shell 執行時，工具執行功能不是沙箱。預設情況下，Python 是啟用的，所以要小心。

遠端 MCP 伺服器

MCP（模型上下文協定）伺服器提供 AI 模型可以呼叫的工具。 Ash 支援遠端 Streamable HTTP MCP 伺服器並將其客戶端會話保持在ash-broker在同一 shell 中跨 Ash 呼叫。

透過將其 URL 本身添加到來註冊伺服器~/.ash/.ash_allow，或運行ash mcp add <url>來自互動式 Ash shell。該命令僅在連接成功後才連接並註冊伺服器：

https://mcpplaygroundonline.com/mcp-complex-server

當 GUI 可用時，OAuth 授權將在桌面瀏覽器中開啟。如果瀏覽器無法打開，Ash會列印一個可複製的授權URL並在終端機中等待。使用ash mcp add <url> --no-browser始終使用此終端流。手動URL授權仍然需要同一主機上的瀏覽器；它不是無瀏覽器的 OAuth 流程。

URL 行開頭為http://或者https://是 MCP 註冊，而不是 shell 指令。方案的辨識不區分大小寫。 Ash 從修剪後的 URL 文字上的 SHA-256 的前 8 個小寫十六進位字元衍生出伺服器的本機名稱。除localhost開發外都需要HTTPS；帶有嵌入憑證、查詢字串或片段的 URL 將被拒絕。對於直接 OAuth 連接，發現僅允許確切註冊的 MCP 機構使用非公共 IP 位址；其他 OAuth 主機仍然受到非公共位址封鎖。配置的出口代理負責過濾其目標位址。變更將在下一個 Ash 請求時讀取。

MCP 註冊保持啟用狀態ASH_STRICT=1。返回的工具輸出仍然被視為不可信的證據。僅註冊您信任的伺服器：他們的工具可能代表您執行操作。對於受 OAuth 保護的伺服器，當 GUI 可用時，Ash 將開啟瀏覽器，同時代理程式處理回調和令牌。憑證使用作業系統憑證管理員（如果可用）或由使用者提供的隨機 32 位元組保護的加密文件ASH_MCP_CREDENTIAL_KEY。現存的~/.ash/mcp.json檔案不再被讀取；將伺服器 URL 移至.ash_allow。

如果 MCP 初始化失敗，Ash 會在沒有遠端 MCP 工具的情況下繼續要求。互動式運行列印警告；非互動式運行會悄悄失敗。排程作業沒有每互動式 shell 代理，因此無法使用遠端 MCP 工具。依賴 MCP 的計劃提示可能仍會運行，但可能會在沒有請求的 MCP 操作或資料的情況下完成。不要安排需要 MCP 的提示。

請參閱MCP常見問題解答快速概覽和設定說明。

指令

ash [--attach path]... [text ...]
運行單一助理請求。--attach將文件（圖像或文件）附加到請求中；可重複的。尺寸限制於ASH_ATTACHMENT_MAX_BYTES目前僅透過網路發送給 OpenAI 相容的供應商。
ash mcp add <url> [--no-browser]
連接並註冊有效的遠端 MCP 伺服器.ash_allow。在桌面瀏覽器中開啟 OAuth 授權（如果可用）；回退到終端機中的可複製 URL。--no-browser始終使用終端流。
ash install [--shell bash|zsh] [--dry-run]
安裝或更新 shell 整合。什麼時候--shell省略，則盡可能使用目前 shell。--dry-run無需寫入即可預覽變更。互動時，安裝也會自動配置AI_ENDPOINT,AI_MODEL， 和AI_AUTH_TOKEN：它更喜歡已設定的雲端供應商 API 金鑰（OpenAI、Anthropic、Google Gemini、Azure OpenAI、Mistral、Cohere、Groq、xAI、DeepSeek、Together AI、OpenRouter 或 HuggingFace），然後是正在運行的本機推理伺服器（Ollama、LM Studio、Locama. GPT4All），否則會提示編號的提供者選單。此型號是從端點的型號清單（如果可用）中選擇的。
ash snooze [duration|off]
暫停自動 shell 提示處理。預設值為五分鐘。持續時間使用 Go 語法，例如30s,5m， 或者1h。使用off立即恢復。
ash update [--version vX.Y.Z] [--yes|--skip-customized]
下載適用於目前架構的最新穩定 macOS、Linux 或 FreeBSD 版本並將其安裝到~/.local/bin/ash。發布需要 Sigstore 驗證和 SHA-256 驗證。

環境

AI_AUTH_TOKEN
可選的不記名令牌。設定後，它作為承載身份驗證發送，並且是雲端點所必需的。專用/LAN 位址（RFC1918 IPv4、IPv6 ULA）和.localmDNS 主機名稱被視為非雲端（例如localhost） 除非ASH_STRICT=1已設定。
AI_CACHE
可選的提供者本機快取切換。支援時預設啟用；使用off或者false禁用。
AI_ENDPOINT
聊天 API 端點所需的基本 URL。
AI_MODEL
傳送到端點的所需模型名稱。
AI_PROVIDER
可選的提供者覆蓋：anthropic,bedrock,cohere,gemini,google,ollama， 或者openai。未設定時，ash 從端點偵測提供者。
AI_TIMEOUT
可選的請求超時。預設:3m。
ASH_ALWAYS_OPENAI_API
可選測試切換。當類似 true 時，路由ollama透過 OpenAI 相容的 SDK 適配器而不是手動實作來提供程式。預設值：開啟。
ASH_ATTACHMENT_MAX_BYTES
透過以下方式傳遞的檔案的可選最大大小（以位元組為單位）--attach。預設:10485760（10 MiB）。
ASH_HISTORY_MAX
每個鍵可選的最大歷史訊息數。預設:40。
ASH_LOG_FILE
啟用詳細日誌記錄時可選的調試日誌路徑。
ASH_LOG_MAX_BYTES
旋轉前可選的最大日誌大小。預設:1048576。
ASH_MAX_AGENTS
一個父進程產生的可選最大子代理數。預設:6。
ASH_MAX_TOOL_ITERS
可選的最大 AI 工具呼叫循環迭代。預設:16。
ASH_RELEVANCE_WINDOW
執行狀態中包含可選的最近工具觀察結果。預設:4。
ASH_RETRY_BASE_DELAY
可選的重試退避基本延遲。預設:250ms。
ASH_RETRY_MAX_ATTEMPTS
可選的可重試請求嘗試。預設:3。
ASH_SCHEDULED_TASK
ash 管理的呼叫所使用的內部調度程序標誌。
ASH_STREAM
可選切換。當 true-like 時，串流來自其適配器支援它的提供者的回應（目前僅限 OpenAI）。預設值：開啟。
ASH_TASK_MAX
從請求派生的執行任務的可選上限。預設:6。
ASH_TASK_STALL_ROUNDS
可選的助理在停車前進行失速輪巡。預設:2。
ASH_ALLOW
可選的以逗號分隔的可執行白名單run_unix_command。否則~/.ash/.ash_allow當存在時使用；此覆蓋不會擴展內部 Ash 標記。
ASH_DENY
可選的以逗號分隔的拒絕列表，用於明確阻止命令、工具和插件。否則~/.ash/.ash_deny當存在時使用。
ASH_TOOL_OUTPUT_MAX
可選的最大捕獲工具輸出（以位元組為單位）。預設:8192。
ASH_TOOL_TIMEOUT
可選的本機工具命令逾時。預設:15s。
ASH_VERBOSE
可選的調試日誌記錄和執行儀表板。值如1,true,on， 和debug啟用它。
SESSION_ID
持久性歷史記錄和日誌命名的會話標識符。丟失時自動產生互動式運行。

文件

  • ~/.ash/.ash_system —規範的系統提示。$TOOLS_DIR_LIST,$PLUGINS_DIR_LIST， 和$IF_PYTHON_AVAILABLE是內部 Ash 替換，而不是環境變數。
  • ~/.ash/.ash_allow —規範命令、工具和插件白名單。它是獨立的$TOOLS_DIR_LIST和$PLUGINS_DIR_LIST指令允許常規託管腳本和本機插件；替換為限制性策略的字面名稱。
  • ~/.ash/.ash_deny —用於阻止特定命令、工具或外掛程式的規範拒絕清單檔案。
  • ~/.ash/plugins/ —本機二進位插件目錄。
  • ~/.ash/history/ —對話歷史記錄文件。
  • ~/.ash/scratch/ —會話範圍的暫存檔案。
  • ~/.ash/.ash_snooze_until —自動提示暫停到期。

退出狀態

ash 成功時傳回 0。當配置、網路請求或工具執行失敗時，它會傳回非零。

範例

echo "summarize this directory" | ash
ash install --shell bash
ash install --shell zsh --dry-run
