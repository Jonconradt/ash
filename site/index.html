01

Opt in to shell integration

ash works with bash, Fish, and zsh. The verified installer asks before adding its managed shell hook; unknown commands become prompts once you enable it. Snooze when you need a break from automatic prompt processing.

02

Easy updates

Update with your package manager, or use ash update for a Release installed under ~/.local/bin. Choose Release, Beta, or Nightly through supported package repositories. No surprise background updates.

03

Stay in control

Tool execution is constrained by explicit allow and deny lists and runs as your user. You decide what ash is allowed to touch. Add your own Python scripts to $XDG_DATA_HOME/ash/tools or native plugins to $XDG_DATA_HOME/ash/plugins.
