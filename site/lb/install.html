Debian an Ubuntu: APT

Viraussetzunge: amd64 oder arm64, Administrator Zougang, APT,curl,gpg, an CA Certificaten. Installéiert fehlend Download / Schlëssel Tools mat Ärer Verdeelung ier Dir de Repository bäidréit. Verëffentlechung gëtt genanntstable:

curl -fsSL https://www.versionx.ai/apt/gpg.key -o versionx-apt.asc
gpg --show-keys --with-fingerprint versionx-apt.asc
sudo gpg --dearmor --batch --yes -o /etc/apt/keyrings/versionx-keyring.gpg versionx-apt.asc
sudo chmod 0644 /etc/apt/keyrings/versionx-keyring.gpg
echo "deb [signed-by=/etc/apt/keyrings/versionx-keyring.gpg] https://www.versionx.ai/apt stable main" |
  sudo tee /etc/apt/sources.list.d/versionx.list
sudo apt update
sudo apt install ash
rm versionx-apt.asc

Initialiséieren an z'iwwerpréiwen

Nodeems Dir Binären installéiert hutt, lafen d'Setup interaktiv wéi Ären normale Benotzer. Wann Dir keng Shellintegratioun wëllt, kënnt Dir nëmmen Ash installéieren. Dëst ass wahrscheinlech net wat Dir wëllt. De reelle Wäert vun ash ass d'Shell Integratioun hei drënner. Assets-only Setup léisst Är Startupdateien onverännert:

D'Installatioun déi Dir wahrscheinlech benotze wëllt, beinhalt d'Shellintegratioun. Dëst wäert Äert .bashrc änneren (oder d'Äquivalent fir Är Shell) fir Ash opzehuelen. Fir d'Kommando net fonnt Integratioun z'aktivéieren, wielt genau ee Kommando fir d'Shell déi Dir benotzt:

Bash benotzt~/.bashrc, zsh benotzt~/.zshrc, a Fësch benotzt$XDG_CONFIG_HOME/fish/config.fish(Standard~/.config/fish/config.fish). Eng nei Schuel duerno opmaachen; bestehend Muschelen behalen hire Lafen Broker. Integratioun prepends~/.local/binop PATH: ewechzehuelen eng al Benotzer-lokal Kopie ier Dir erwaart datt e System Package ausgewielt gëtt.

Wann Provider Astellunge feelen, detektéiert de Setup existent Providerschlësselen oder e lafende lokale Server; soss bitt et e Provider Menü an Ufro fir Umeldungsinformatiounen. Wielt e verfügbaren Tool-fähig Modell. Bestehend gëlteg Astellunge sinn erhale bleiwen, sou datt d'Wiederlaaf vum Setup kee Provider-Switch Kommando ass.

Astellunge sinn gespäichert an$XDG_CONFIG_HOME/ash/.ash_env(Standard~/.config/ash/.ash_env, privat Dateierechter). Managed Integratioun lued se. Ouni Integratioun kënnen Bash / zsh Benotzer dës Datei an hirer normaler Startkonfiguratioun Quell; Fësch Benotzer sollen déi entspriechend FormatiounASH_AI_*Variabelen mat Fish Syntax, net Quell vun der Bash-Format Datei. Schützt all Datei mat Tokens an engagéiert se ni.

Fir eng Benotzer-lokal Installatioun ouni Integratioun, füügt säin aktuellen Verzeechnes op PATH. Bash/zsh:export PATH="$HOME/.local/bin:$PATH". Fësch:fish_add_path "$HOME/.local/bin". Bleift dëst mat der Startkonfiguratioun vun Ärer Shell; ersetzt Äre personaliséierten Installatiounsverzeechnes wann zoutreffend.

Skriptinstallatioun: eng Alternativ, net déi éischt Wiel

Preferenz Homebrew, APT, DNF oder Pacman: si verfollegen Besëtzer Dateien, verifizéieren Downloads mat hirer Vertrauenskonfiguratioun a liwweren vertraute Updates / Entfernung. Si erfuerderen nach ëmmer vertrauenswürdege Verëffentlecher a Paketinstallatiounsaktiounen.

E Websäit Skript leeft Code mat den Permissiounen vun Ärem Kont. Eng kompromittéiert Websäit, Verëffentlecher oder Ännere Skript kann Geheimnisser liesen, Dateien änneren oder aner Software installéieren. HTTPS schützt den Transport, net d'Intentioune vun deem Code. Piping eng URL direkt op eng Shell féiert se aus ier Dir et iwwerpréift. D'Archiv-Ënnerschrëft Kontrollen vum Skript authentifizéieren de Skript selwer net. Laf et ni mat sudo oder deaktivéiert seng Verifizéierung.

Viraussetzunge: eng ënnerstëtzt OS / Architektur,$SHELLidentifizéieren Bash / zsh / Fësch,Sigstore cosign,tar,uname,install, Standard Shell Utilities, e SHA-256 Kommando (sha256sum,shasum, odersha256), an en Downloader (curl,wgetoder Python). D'Beispill benotzt Curl. FreeBSD brauch och Bash. Ären Heem / Installatiounsverzeichnis muss schreiwenbar sinn.

Eroflueden op eng lokal Datei, kontrolléiert et mat engem Editor, an ausféiert nëmmen wann Dir seng Quell a Verhalen vertraut. Inspektioun ass keng Garantie fir Sécherheet; lafen dës Schrëtt net blann aus:

No der Inspektioun, lafen déi gespäichert Kopie als Ären normale Benotzer:

install.shLuet déi lescht Verëffentlechung erof, verifizéiert säi Sigstore-ënnerschriwwene Checksum Manifest an Archivverdauung, an installéiertash/ash-brokeran~/.local/bin. Ouni en interaktiven Terminal kënnen d'Provider / Integratiounsprompts iwwersprongen ginn: lafenash installinteraktiv duerno.

Dir kënnt setzenASH_INSTALL_DIRier Dir de Skript leeft fir eng aner Destinatioun ze wielen. Füügt dës Destinatioun op PATH selwer.Self-Update gëtt nëmmen ënner ënnerstëtzt~/.local/bin; Benotzerdefinéiert Destinatiounen erfuerderen manuell Ersatz. De Skript huet kee Beta / Nightly Selector.

Verifizéiert en direkten Package oder Archiv

Viraussetzunge: Cosign an e SHA-256 Utility. Vun der selwechter publizéierter Verëffentlechung, luet Äre Package / Archiv erof,SHA256SUMS,an anSHA256SUMS.sigstore.json. Schafft an engem neie Verzeechnes. ErsetzenvX.Y.Zmam genauen Tag, mat engem Prerelease Suffix, wann zoutreffend:

cosign verify-blob SHA256SUMS \
  --bundle SHA256SUMS.sigstore.json \
  --certificate-identity "https://github.com/Jonconradt/ash/.github/workflows/release.yml@refs/tags/vX.Y.Z" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"

Eréischt nodeems dat geléngt, berechnen Äre Fichier Verdauung matshasum -a 256 PACKAGEop macOS,sha256sum PACKAGEop Linux, odersha256 -q PACKAGEop FreeBSD. ErsetzenPACKAGEmam erofgeluede Dateinumm a vergläicht et genau mat deem Dateinumm seng Entrée am verifizéierte Manifest. Stop op engem vermësst Entrée oder all Mëssverständnis. En net ënnerschriwwene Checksum, deen nieft engem Fichier erofgeluede gëtt, ass net gläichwäerteg mat verifizéierte Verëffentlecher Metadaten.
