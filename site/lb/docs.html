Remote MCP Serveren

MCP (Model Context Protocol) Servere bidden Tools en AI Modell kann uruffen. Ash ënnerstëtzt Remote Streamable HTTP MCP Serveren an hält hir Client Sessiounen anash-brokeriwwer Ash Opruff an der selwechter Réibau.

https://mcpplaygroundonline.com/mcp-complex-server

OAuth Autorisatioun mécht am Desktop Browser op wann e GUI verfügbar ass. Wann de Browser net opgemaach ka ginn, dréckt Ash eng kopéierbar Autorisatiouns-URL aus a waart am Terminal. Benotztash mcp add <url> --no-browserfir ëmmer dësen Terminalflow ze benotzen. Manuell URL Autorisatioun erfuerdert nach ëmmer e Browser um selwechten Host; et ass keen browserlosen OAuth Flow.

URL Linnen ugefaange mathttp://oderhttps://sinn MCP Aschreiwungen, net Shell Kommandoen. Schemae ginn case-onsensibel unerkannt. Ash ofgeleet de lokalen Numm vum Server vun den éischten 8 kleng hexadezimal Zeeche vun SHA-256 iwwer den ofgeschniddenen URL Text. HTTPS ass erfuerderlech ausser fir localhost Entwécklung; URLen mat embedded Umeldungsinformatiounen, Ufro Strings oder Fragmenter ginn ofgeleent. Fir direkt OAuth Verbindungen erlaabt Entdeckung Net-ëffentlech IP Adressen nëmme fir déi exakt registréiert MCP Autoritéit; aner OAuth-Host bleiwen ënner net-ëffentlech-Adress-Blockéierung. E konfiguréierten Egress Proxy ass verantwortlech fir seng Destinatiounsadressen ze filteren. Ännerungen ginn op déi nächst Ash Ufro gelies.

MCP Aschreiwungen bleiwen aktivéiert matASH_STRICT=1. Zréckgeschéckt Outil Output gëtt ëmmer nach als net zouverlässeg Beweiser behandelt. Registréiert nëmmen Serveren déi Dir vertraut: hir Tools kënnen Handlungen aus Ärem Numm maachen. Fir OAuth-geschützte Serveren, Ash mécht de Browser op wann e GUI verfügbar ass, während de Broker den Callback an Tokens handhabt. Umeldungsinformatiounen benotzen den OS Umeldungsmanager wann verfügbar, oder eng verschlësselte Datei geschützt vun engem Benotzer geliwwert zoufälleg 32-ByteASH_MCP_CREDENTIAL_KEY. Bestehend~/.ash/mcp.jsonDateien ginn net méi gelies; réckelen Server URLen an.ash_allow.

Wann d'MCP Initialiséierung feelt, fiert Ash d'Ufro weider ouni Remote MCP Tools. Interaktiv leeft Drécken eng Warnung; net-interaktiv Lafen versoen roueg.Geplangte Aarbechtsplazen hunn net de per-interaktiven-Shell Broker an dofir kënnen d'Remote MCP Tools net benotzen.Eng geplangte Prompt, déi vum MCP ofhängt, kann nach lafen, awer kann ouni déi ugefrote MCP-Aktioun oder Daten fäerdeg sinn.
