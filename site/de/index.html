01

Shell-Integration aktivieren

ash funktioniert mit Bash, Fish und ZSH. Das verifizierte Installationsprogramm fragt, bevor es seinen verwalteten Shell-Hook hinzufügt. Unbekannte Befehle werden zu Eingabeaufforderungen, sobald Sie sie aktivieren. Machen Sie eine Schlummerfunktion, wenn Sie eine Pause von der automatischen Eingabeaufforderungsverarbeitung benötigen.

02

Einfache Updates

ash update hält Ihre Installation auf dem neuesten Stand. Der Befehl führt automatisch Versionsprüfungen, Downloads und Verifizierungen durch. Keine Hintergrund- oder Überraschungsupdates.

03

Behalten Sie die Kontrolle

Die Ausführung des Tools wird durch explizite Zulassungs- und Verweigerungslisten eingeschränkt und wird als Ihr Benutzer ausgeführt. Sie entscheiden, wasashdarf anfassen. Fügen Sie Ihre eigenen Python-Skripte hinzu$XDG_DATA_HOME/ash/toolsoder native Plugins zu$XDG_DATA_HOME/ash/plugins.

Benutzer von Linux, macOS und FreeBSD können die neueste Version in einem Schritt installieren. Installieren Sie Sigstorecosignzuerst, damit das Installationsprogramm das signierte Prüfsummenmanifest überprüfen kann. Es wird installiert~/.local/binund fragt vor dem Hinzufügen der optionalen Fish-, ZSH- oder Bash-Shell-Integration.

Auf macOS oder Linux mitHomebrew, installierenashund seine gebündelten Plugins, dann initialisieren Sie seine eingebetteten Assets, Anbietereinstellungen und Shell-Integration:

brew install Jonconradt/ash/ash
ash install --shell $SHELL --shell-integration

Die Formel wird für jede stabile Version automatisch aktualisiert. Der Installationsbefehl stellt bereitAsh, richtet die Shell-Integration für Ihre aktuelle Shell ein und hilft bei der Konfiguration Ihres KI-Anbieters.

Unter Debian oder Ubuntu installieren und aktualisierenashmitGEEIGNET; auf Fedora- und RHEL-kompatiblen Systemen verwendenDNF; Benutzer von Arch Linux können es verwendenPacman.

ash installKonfiguriert Ihren KI-Anbieter automatisch: Er erkennt einen bereits festgelegten Cloud-Anbieter-API-Schlüssel oder einen laufenden lokalen Inferenzserver. Andernfalls wird ein nummeriertes Menü zur Auswahl eines Anbieters und Modells angezeigt. Oder stellen Sie diese selbst ein:

export ASH_AI_AUTH_TOKEN='your-token'
export ASH_AI_ENDPOINT='https://ollama.com'
export ASH_AI_MODEL='gemma4:31b-cloud'

Local, OpenAI, Anthropic, Google, Azure OpenAI, Mistral, Cohere, Groq, xAI, DeepSeek, Together AI, OpenRouter, HuggingFace, AWS Bedrock und alle anderen Anbieter mit einer OpenAI-kompatiblen API werden unterstützt.

curl -fsSL https://jonconradt.github.io/ash/install.sh | sh
