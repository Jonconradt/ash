01

Installieren Sie die Shell-Integration

ash funktioniert mit Bash, Fish und ZSH. Unbekannte Befehle werden zu Eingabeaufforderungen, ohne dass sich Ihre normalen Befehlsgewohnheiten ändern. Machen Sie eine Schlummerfunktion, wenn Sie eine Pause von der automatischen Eingabeaufforderungsverarbeitung benötigen.

02

Einfache Updates

ash update hält Ihre Installation auf dem neuesten Stand. Der Befehl führt automatisch Versionsprüfungen, Downloads und Verifizierungen durch. Keine Hintergrund- oder Überraschungsupdates.

03

Behalten Sie die Kontrolle

Die Ausführung des Tools wird durch explizite Zulassungs- und Verweigerungslisten eingeschränkt und wird als Ihr Benutzer ausgeführt. Sie entscheiden, was ash anfassen darf. Fügen Sie Ihre eigenen Python-Skripte zu ~/.ash/tools oder native Plugins zu ~/.ash/plugins.

Linux-, macOS- und FreeBSD-Benutzer können die neueste Version in einem Schritt installieren. Das Installationsprogramm überprüft den Download, installiert auf ~/.local/bin und konfiguriert die erkannte Fish-, ZSH- oder Bash-Integration, wobei auf Bash zurückgegriffen wird.

ash install konfiguriert Ihren KI-Anbieter automatisch: Es erkennt einen bereits festgelegten Cloud-Anbieter-API-Schlüssel oder einen laufenden lokalen Inferenzserver, andernfalls zeigt es ein nummeriertes Menü zur Auswahl eines Anbieters und Modells an. Oder legen Sie diese selbst fest:

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'

Local, OpenAI, Anthropic, Google, Azure OpenAI, Mistral, Cohere, Groq, xAI, DeepSeek, Together AI, OpenRouter, HuggingFace, AWS Bedrock und alle anderen Anbieter mit einer OpenAI-kompatiblen API werden unterstützt.
