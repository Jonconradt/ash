01

Instalar la integración del shell

ash funciona con bash, Fish y zsh. Los comandos desconocidos se convierten en indicaciones sin cambiar sus hábitos de comando normales. Posponga la repetición cuando necesite un descanso del procesamiento automático de mensajes.

02

Actualizaciones sencillas

ash update mantiene su instalación actualizada con la última versión. El comando maneja automáticamente las verificaciones, descargas y verificaciones de versiones. Sin antecedentes ni actualizaciones sorpresa.

03

Mantenga el control

La ejecución de la herramienta está restringida por listas explícitas de permiso y denegación y se ejecuta como su usuario. Tú decides qué ash puede tocar. Agregue sus propios scripts de Python a ~/.ash/tools o complementos nativos a ~/.ash/plugins.

Empiece poco a poco

Dale a tu caparazón
un poco de compañía.

Los usuarios de Linux, macOS y FreeBSD pueden instalar la última versión en un solo paso. El instalador verifica la descarga, instala en ~/.local/bin y configura la integración Fish, zsh o bash detectada, recurriendo a bash.

ash install configura automáticamente su proveedor de IA: detecta una clave API de proveedor de nube ya configurada o un servidor de inferencia local en ejecución; de lo contrario, muestra un menú numerado para elegir un proveedor y modelo. O configúrelos usted mismo:

export AI_AUTH_TOKEN='84…89'
export AI_ENDPOINT='https://ollama.com'
export AI_MODEL='gemma4:31b-cloud'

Se admiten Local, OpenAI, Anthropic, Google, Azure OpenAI, Mistral, Cohere, Groq, xAI, DeepSeek, Together AI, OpenRouter, HuggingFace, AWS Bedrock y cualquier otro proveedor con una API compatible con OpenAI.
